In short

  • FrostCopy runs only on your computer. The program has no built-in internet connection, and everything that reads your documents runs locally. Nothing you open in FrostCopy is sent out of the program.

1. What FrostCopy is

FrostCopy is a tool for finding and removing personal information in documents. The program uses rules and word lists to recognize information such as names, Social Security numbers and other ID numbers, contact information, health information and account numbers. In images it looks for faces so they can be pixelated; it does not recognize who anyone is. You can also mark and remove information in the documents yourself. FrostCopy makes new copies in which what is marked is removed or replaced. The copies can still contain personal information.

Detection is automatic and can be wrong. FrostCopy can find too little and too much.

What FrostCopy cannot clean, it takes out of the copy instead of leaving it in:

  • attachments in email files that are not text (PDF, Word, images); clean them as separate files
  • macros, embedded objects and preview images in Word, Excel and PowerPoint files
  • EMF and WMF images, which can contain text FrostCopy cannot read; they are replaced with a blank image

Every copy is read in full before it is saved. If anything that was found is still in it, the copy is not saved, and the report names the file. This final check can also miss things.

2. Everything happens on your computer

FrostCopy is built to work entirely without the internet. This is not a setting that can be turned off, but part of how the program is made:

  • FrostCopy has no function for connecting to the internet. The program contains no network client, sends no data, downloads no updates and has no tracking or usage statistics.
  • The models FrostCopy uses, for example to read sentences and to find faces in images, come with the program and run inside FrostCopy on this computer. They have no network port and no connection to any cloud service.
  • The FrostCopy window is locked so that it cannot load or send anything over the network.
  • Every build is checked automatically for network code before it is delivered.
  • You can check this yourself: FrostCopy works the same with the network turned off, and a firewall will see no traffic from FrostCopy.

This applies to FrostCopy as delivered by ESBJUG CONSULT. It cannot protect against:

  • modified or counterfeit copies of the program. Use only copies you received directly from ESBJUG CONSULT.
  • malware, remote access or other programs on your computer
  • services you store the files in yourself. If you put originals or cleaned copies in a folder that syncs, for example iCloud, OneDrive, Dropbox or Google Drive, that service sends the files on, regardless of FrostCopy.
  • operating system features, such as updates and security checks, that FrostCopy does not control

3. Limits of automatic detection

FrostCopy cannot make sure that all personal information is found or removed. In particular, the program can:

  • miss information, including information that identifies a person directly, such as names and Social Security numbers
  • miss information in images, scanned pages, handwriting, tables, comments, metadata, attachments and embedded files
  • miss information that identifies someone only together with other information
  • remove too much, so that the content becomes misleading or unusable
  • give different results for similar documents, depending on format and quality

If FrostCopy finds nothing, that does not mean the document is free of personal information. The risk assessment in the program is an automatic calculation that can be wrong, both in what it finds and in how serious it judges it to be. It does not say that a document is safe to share, and it must not be used as the basis for sharing, publishing, filing or releasing a document.

5. Your files

  • FrostCopy reads the originals and never changes, moves or deletes them. The program can only write to a new folder it creates next to the originals, for example “Cases-clean”. If that folder already exists, “Cases-clean 2” is created, so nothing is overwritten.
  • Before you open a folder, you confirm that you have your own copy of it. Make that copy outside FrostCopy, for example on another drive.
  • As an extra safeguard, FrostCopy copies the files you choose into an encrypted backup in the program’s own folder before the scan. You can turn this off before the scan and in Settings. The backup contains the originals, with all the personal information in them, can only be opened on this computer, and stays there until you delete it under “Backups”. FrostCopy reminds you of backups older than 30 days.
  • The cleaned copies are missing information on purpose. Keep the originals. You are responsible for storing and deleting originals, cleaned copies and backups in an appropriate way.
