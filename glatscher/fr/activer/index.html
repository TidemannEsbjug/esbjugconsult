Glatscher · Licence

Saisir la clé de licence

Glatscher est gratuit pour les particuliers, et gratuit pendant 30 jours pour les organisations. Ensuite, l’organisation a besoin d’une licence. Le logiciel lui-même ne se connecte jamais à Internet.

  1. Ouvrez Glatscher et cliquez sur « Licence » en haut à droite. Pendant l’essai, il est écrit « Essai : … jours restants ».
  2. Collez dans le champ le code reçu dans notre e-mail. Il commence par GLATSCHER-. Sur Mac, vous pouvez aussi double-cliquer sur le fichier .glatscherlizenz joint à l’e-mail.
  3. Cliquez sur « Activer ». La licence vaut pour toute l’organisation : transmettez-la avec « Partager avec des collègues ».
