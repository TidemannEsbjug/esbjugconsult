Confidentialité

Vos données restent chez vous.

Glatscher a été conçu pour que les données personnelles ne tombent pas entre de mauvaises mains. Cela vaut aussi pour les vôtres. Voici ce qui se passe dans le logiciel, sur le site et lors de l’achat.

En bref

  • Le logiciel n’envoie rien. Vos documents ne quittent jamais votre ordinateur, et nous ne les voyons jamais.
  • Le site ne vous suit pas. Les pages de Glatscher ne déposent aucun cookie et ne contiennent ni publicité ni outil d’analyse de tiers.
  • Si vous commandez, nous conservons ce qui est nécessaire à la facture et à la livraison. Le nom et l’adresse de l’organisation, l’adresse e-mail, votre référence ainsi que le type et la taille de l’organisation.

Pour toute question sur la protection des données, écrivez à tidemann@esbjugconsult.com. C’est une personne qui vous répond.

Le logiciel

Glatscher ne peut pas se connecter à Internet. Le logiciel n’a ni compte, ni statistiques d’utilisation, ni rapports d’erreur, ni mises à jour automatiques. Il n’y a rien que nous puissions collecter.

Vos documents
Ils sont lus et occultés sur votre ordinateur. Nous ne les recevons jamais et ne les traitons pas pour votre compte. Pour les documents, c’est vous, ou votre organisation, qui êtes responsable du traitement.
Ce que Glatscher enregistre
Vos choix pour un dossier, vos propres marquages, les sauvegardes et la clé sont enregistrés chiffrés sur votre ordinateur. Vous pouvez les supprimer à tout moment.
La licence
Le code de licence est vérifié sur l’ordinateur. Le logiciel ne nous demande pas s’il est valable.
Quand le logiciel ouvre le site
Si vous cliquez sur « Acheter une licence », notre page d’activation s’ouvre dans votre navigateur. L’adresse contient un code machine qui identifie l’installation. Il ne dit rien de vos documents, et nous ne le conservons pas.

Votre service informatique peut le vérifier lui-même. Voir les contrôles sur la page pour l’informatique.

Le site

Les pages de Glatscher se trouvent sous esbjugconsult.com/glatscher. Les polices, les images et les scripts sont chargés depuis notre propre serveur, rien depuis d’autres sites.

Cookies
Les pages de Glatscher n’en déposent aucun.
Comptage des visites
Nous comptons les visites pour savoir si les pages sont consultées. Pour chaque visite, nous enregistrons l’heure, la page consultée, la ville et le pays (estimés à partir de l’adresse IP) et s’il s’agit d’un mobile ou d’un ordinateur. L’adresse IP n’est pas enregistrée.
Nouvelle visite ou retour
Pour distinguer les deux, nous calculons un code à partir du réseau depuis lequel vous vous connectez. Ce code ne permet pas de retrouver l’adresse IP. Il est enregistré avec la ville et l’heure. Si vous avez accepté les cookies sur la page d’accueil d’esbjugconsult.com, c’est ce cookie qui est utilisé à la place.
Vérification de l’ordinateur
Ce que vous saisissez sous « Glatscher fonctionne-t-il sur votre ordinateur ? » est recherché dans notre propre liste. La recherche n’est pas enregistrée.
Téléchargement
Nous ne comptons pas les téléchargements et ne les rattachons à aucune organisation.
Erreurs de notre côté
Si quelque chose ne fonctionne pas, nous journalisons l’erreur. En cas d’erreur d’envoi d’un e-mail, le journal peut contenir l’adresse du destinataire.

Le site est hébergé chez Cloudflare. Comme pour tout site, le prestataire qui délivre la page doit voir votre adresse IP pour pouvoir vous l’envoyer.

Lors de la commande

Pour les particuliers, Glatscher est gratuit ; nous n’avons alors besoin de rien de votre part. Une organisation qui commande une licence sur facture nous transmet ce qui suit :

L’organisation
Le nom et l’adresse de facturation, tels que vous les saisissez. Nous ne consultons aucun registre. Une entreprise individuelle porte souvent le nom de son exploitant ; ce nom est alors une donnée personnelle.
Type et taille
S’il s’agit d’une entreprise, d’une commune ou d’un autre organisme public, avec le nombre de personnes et le secteur, le nombre d’habitants ou le nombre d’agents. Le prix en dépend.
Adresse e-mail
L’adresse à laquelle sont envoyées la facture, puis la clé de licence.
Votre référence
Votre numéro de bon de commande ou votre référence, et le cas échéant votre numéro IDE ou de TVA, si vous les indiquez. Elle figure sur la facture.
Le paiement
Le paiement se fait uniquement sur facture, que nous envoyons nous-mêmes par e-mail, par virement sur notre compte bancaire. Nous n’acceptons pas les cartes, et aucun prestataire de paiement n’intervient. Nous conservons la commande, le montant, la date de facture et le fait que la facture est payée ou non.
La clé de licence
La clé contient le nom de l’organisation, l’adresse e-mail de la commande et la période de validité de la licence. Toute personne qui reçoit la clé peut lire ces informations.

Nous gardons une copie des e-mails que nous envoyons, afin de savoir ce que vous avez reçu.
